# Regole di Sviluppo Angular

- **Approccio diretto**: Rispondi fornendo direttamente il codice senza preamboli, monologhi interni o tag `<think>`.
- **Angular Moderno**: Usa la sintassi standalone (`standalone: true`), Signals per la gestione dello stato e la nuova control flow syntax (`@if`, `@for`).
- **TypeScript**: Garantisci una tipizzazione forte ed evita categoricamente l'uso di `any`.
